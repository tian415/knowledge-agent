## 本次公开整理中修复的问题

1. **普通 clone 的 Git 目录**：旧 Writer 与 Store 直接把 `.git` 当文本读取。新副本复现 `EISDIR` 后修复，目录和工作树指针分开处理；代码根仍受保护。
2. **缺少作者的 Vault**：旧路径诊断在根目录缺失时抛错，导致旧材料演示失败。改为返回缺失提示并保持待审核；不创建目录、不放宽 symlink 防护。
3. **macOS 固定临时目录**：演示及部分测试改为解析系统临时目录的真实路径，保留“不接受符号链接祖先”的约束。
4. **私人配置隔离**：Registry 的个人路径改为通用默认值或显式环境变量，发布包提供空覆盖配置。历史私有材料、运行账本和付费/迁移脚本不进入公开快照。
