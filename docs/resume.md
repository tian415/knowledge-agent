# 简历与面试项目说明

## 项目表述

**Knowledge Agent｜本地优先 AI 知识工作流｜Node.js / JavaScript / Markdown**

个人项目，AI 辅助开发。以下动词需与本人实际负责的范围一致。

- 设计并实现从授权对话、增量主题整理到人工审核和 Markdown 保存的本地知识工作流，支持来源追溯与持续更新。
- 将模型语义提案与确定性执行分离，通过来源版本、逐字证据、预览摘要和文件哈希校验，保护人工笔记并拒绝过期写入。
- 实现幂等保存、持久化处理记录和受控恢复，提供无需模型密钥的隔离演示与覆盖关键写入边界的自动化回归。

## 面试演示路线

先展示两段合成讨论如何形成同一主题，再保存第一版、加入新讨论、预览增量并恢复第二次写入。解释为什么保存必须绑定预览和目标文件状态，以及为什么完整性未知的来源不能推断删除。

可以结合 `tests/capture/product-flow.test.mjs` 讲清楚一次人工编辑冲突：旧预览拒绝覆盖，而不是自动重试。另一个具体案例是普通 clone 的 `.git` 为目录，与 linked worktree 的指针文件不同，公开版必须分别处理并验证。

## 证据与限制

可复现结果见 [验证记录](verification.md)。本地开发阶段有经授权的真实笔记保存记录；公开仓库不包含这些私人原文，不能让读者仅凭公开演示验证真实语义质量。

不写全账号同步、生产级稳定运行、Jev 已接入、自动化准确率、活跃用户量或节省时间百分比。自动化回归数量不作为效果指标。尚未完成的真实质量和复用评估应如实说明。
