# 合成演示指南

演示调用实际 Store、Publisher、Writer 和 HTTP 接口；语义内容为固定合成结果。它验证工程流程，不验证 AI 内容质量。

## 启动

安装 Node.js 24+ 后，在项目目录执行：

```bash
npm ci --ignore-scripts
npm run demo:product
```

服务只监听 `127.0.0.1`，默认使用系统分配的空闲端口。输出 JSON 中：`home` 为网页入口，`private_directory` 为本轮临时目录，`config` 为合成配置。每次启动创建独立目录，不复用真实状态。无需 Obsidian 客户端。

## 完整走一遍

1. 首页最初没有保存记录，这是正常状态。点击侧栏“草稿审查”，再点击“原文保真与增量整理”进入主题详情。
2. 展开“查看来源”，点击“查看本主题完整已读原文”，核对 Codex 与 ChatGPT 两个合成来源。
3. 点击“查看保存预览”，查看 Markdown 正文；勾选确认后点击“确认保存到笔记”。
4. 点击“维护概览”或“保存记录”，应出现第一版实际保存记录。
5. 点击“来源与运行”，展开“来源配置与手动读取”，点击“演示：新增一段对话”。
6. 返回“草稿审查”，重新预览。第二版增加 BOM 与 CRLF 的字节保真说明，更新同一个文件。
7. 保存第二版。进入“保存记录”，点击最新一项进入详情，再展开“查看恢复范围”，勾选并确认恢复，应回到第一版。

若目标文件在预览后被人工修改，保存会拒绝；若保存后被修改，恢复会拒绝。不要删除状态记录来绕过这些检查。

## 停止与数据

`Ctrl+C` 停止。为便于检查，演示目录保留在系统临时目录中；它包含本次合成状态和笔记。需要清理时只移除本轮终端给出的那个 `private_directory`，不要批量清理系统临时目录。它可能被系统自动清理，不用于正式知识保存。

## 常见问题

- 页面打不开：确认进程仍运行，使用终端打印的完整 `home` 地址。也可指定端口：`npm run demo:product -- --port 3218`。
- Node 版本不支持：用 `node --version` 核对 24 或更新版本。
- 数据路径拒绝：真实模式要求私有、非符号链接路径。演示自动解析系统临时目录，无需手工指定 Vault。
- 点击主页的“行动与项目”：这是同一服务里的辅助工作台，材料模型入口在统一演示中关闭。
- 主演示能运行但外部检索不可用：主流程不依赖 Python、Basic Memory 或向量库。
