# Knowledge Agent showcase

This is an isolated public-source snapshot. Node.js 24+, ES modules, native HTTP/browser JavaScript. `npm ci --ignore-scripts`, `npm test`, `npm run demo:product` are the default setup, regression and synthetic demonstration.

Preserve UTF-8 source bytes, partial-history semantics, human feedback, stale-source rejection, reviewed preview hashes, file conflict checks and rollback safety. Tests use synthetic inputs and private temporary stores. Never run a real model or write a real Vault as part of tests.

Private conversations, machine bindings, runtime state and historical paid/migration scripts are intentionally absent. Do not reconstruct them. Existing external integrations are optional and not implied by a green deterministic suite. Do not publish or push without the user's explicit approval.
